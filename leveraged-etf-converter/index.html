R = 当日涨跌幅，L = 倍数，P = 价格。

产品涨跌 = L × R　·　反查：R = 产品涨跌 ÷ L

多日收益 = Π(1 + L × rᵢ) − 1，逐日复利，不能用 L × 多日涨跌

正式基准：TQQQ / SQQQ 跟踪 NDX（纳斯达克100指数）的每日 ±3 倍，QQQ 只是近似代理；SPYU 跟踪 SPXT（标普500全收益指数）的每日 4 倍

联动估算（统一计算函数，正向 / 反向 / 情景表共用）：r = 目标 SPX ÷ 基准 SPX − 1；rNDX = β × r；SPY = 基准 ×(1+r)、SPYU = 基准 ×(1+4r)、QQQ = 基准 ×(1+rNDX)、TQQQ = 基准 ×(1+3rNDX)、SQQQ = 基准 ×(1−3rNDX)。β 为 SPX→NDX 历史加权回归（衰减 0.97），数值、样本数与 R² 见联动卡；这是统计关系，不是换算公式

注意：杠杆倍数只对当日有效、每日收盘后重置。隔夜和多日持有不等于倍数 × 多日涨跌，震荡市会有波动磨损（volatility decay），实际结果还会受费用与日内路径影响。SPYU 是 BMO 发行的 ETN（非 ETF，带发行人信用风险；其每日扣减不止一项费率，见下方成本拆解）；SPX 是指数本身、不能直接买卖。本页为换算工具，不构成投资建议。

SPYU 成本拆解（BMO 定价文件口径）

不能只看一个费率：BMO 定价文件规定，除费用部分外，还按 3 倍融资部分每日计融资成本。三块要分开看——

费用部分 0.95%/年　·　融资加点 2.00%（初始值，发行人可调整）　·　融资基准利率 = 银行优惠贷款利率，最新可核实 7.00%

年化总扣减（按上述利率假设）= 0.95% + 3 × (7.00% + 2.00%) = 27.95%，约合每自然日 0.077%、一周约 0.54%

27.95% 是在「优惠利率 7.00%、融资加点维持初始 2.00%」假设下算出的费用＋融资总扣减率，不是基金公布的管理费率；基准利率或加点一变，实际扣减随之变化。它与回测里 SPYU 每天系统性跑输公式约 0.1% 的量级吻合（见下方历史验证）。

四种「价格 / 费用」不要混：① 投资者费用（0.95%/年那部分，从指示价值中扣）；② 融资费用（3 倍融资部分按基准利率＋加点每日计，见上）；③ 指示价值（indicative value）——按公式扣费后的理论值，盘中由发行人发布；④ 实际市场价格——交易所成交价，可相对指示价值溢价或折价。本页换算出的是按倍数公式的估算价，既不是指示价值、也不是实时成交价。

历史验证（回测）

数据：Yahoo Finance，2026-08-06 → 2026-11-05，共 65 个交易日、64 组隔日对照。用「昨日收盘价 × (1 + L × 标的当日涨跌)」预测产品收盘价，与实际收盘价比对。

单日公式预测误差（分红调整后的总回报口径，即用调整收盘价计算）：平均 0.06%–0.14%，最大 0.7%——公式本身成立，误差来自费用与跟踪偏差

口径说明：同一批数据若改用原始收盘价口径，最大单日误差是 1.4%（出现在 SQQQ 除息日，见末条）。0.7% 与 1.4% 不矛盾——前者已按总回报口径剔除分红跳空，后者没有；引用误差数字时必须带口径

统计排除条件：总回报口径的误差统计（平均 0.06%–0.14%、最大 0.7%）使用分红调整后收盘价，除息日的原始价跳空不计入该组统计、只在原始价口径下单列（即 1.4% 那笔）；无前一交易日收盘价可比对的样本（如长假后首日缺隔日配对）同样不计入 64 组对照

2026-11-05 当天：TQQQ 实际 −18.91%，按 QQQ（−6.49%）算 −19.47%，差 0.56 个百分点；按其正式基准 NDX（−6.36%）算 −19.07%，只差 0.16 个百分点——这就是换算器加 NDX 精算模式的原因

SPYU 每天系统性少约 0.1%（费用 + 3 倍融资部分的每日扣减，拆解见上方「SPYU 成本拆解」），一周累积约 0.5%——是真实磨损，不是公式错误

多日不能直接乘：20 天窗口里 SPYU 平均比「倍数 × 多日涨跌」少 2.43 个百分点；TQQQ 在 −1.5 ～ +3.3 个百分点之间不定；SQQQ 在震荡市反而能多赚，最多 +8.1 个百分点
